On-call

A puzzle game about fixing bugs at 3 a.m.

ALERT · 3:07 AM Bugs in the server. Site going down.

When a website breaks in the middle of the night, the on-call engineer gets out of bed to fix it. Tonight, that's you. Add code to the server and squash every bug before everything crashes.

MUSIC

How to fix it: bugs come in three colours, and so does your code. Each block has two coloured halves. Line up four or more of one colour, across or down, and the code compiles away, taking any bugs with it. Let the code pile up to the top and the server crashes. Fix it fast: solo clears are timed, and your best time at each level and speed is kept as a record.

Each player sets up with their own keys: turn / drop keys pick a row, move keys change it. M changes the music and R shows your records. In a solo game the arrow keys work too. Esc pauses.
