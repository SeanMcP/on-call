ON-CALL

It's after hours. The pager just went off.

MUSIC

You are the on-call engineer. Throw two-colour code blocks into the server. Line up four or more of one colour, across or down, and they compile away, taking any bugs with them. Clear every bug to resolve the incident. If the stack reaches the top, the server crashes.

Each player sets up with their own keys: turn / drop keys pick a row, move keys change it. M changes the music. In a solo game the arrow keys work too. Esc pauses.
